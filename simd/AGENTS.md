# simd: notes for agents

What is not obvious from the code of this library. The rules that hold for every library, the commands and the map of the libraries are in [../AGENTS.md](../AGENTS.md); the user facing description is in README.md.

- Dispatch by instruction set, from the research of odin_plug's `dsp`: `simd.odin` (`Level` ladder SCALAR, SSE2, SSE3, SSSE3, SSE41, SSE42, AVX, AVX2, AVX512 and NEON, SIMD128; `LevelFromName`, `LevelClamp`, `FEATURES_*` for `@(enable_target_feature)` with `-slow-unaligned-mem-32`, `LevelBuild()`), `cpu.odin` + `cpu_x86.odin` (CPUID, XGETBV, vendor and brand) + `cpu_other.odin` (a `when`, not a build tag: "everything but x86" cannot be one) + `cpu_env.odin` (`SIMD_LEVEL`, `#+build !js`), `table.odin` (`Table($P)`, `TablePick`, `TableUseful`), `manager.odin` (`Manager`: clients with priority, wide slots in a queue, `ManagerFavor`, `ManagerRelease` / `ManagerAcquire`, `ManagerSelect`, a generation counter), `example/` (a dot product kernel per level, tested at -o:none, minimal, speed), `tool/info` (`odin run simd/tool/info -o:speed -- --bench [--data <folder>]`), `tool/gen` (fixed seed data files for the text benchmarks), `text.odin` + `text_vector.odin` + `text_vector_x86.odin` (the text kernels per level and the maximal subpart UTF-8 rules; tables are filled by an `@(init)` before any thread, never lazily; kernels with 256 and 512 bit vectors load inline, no helper without the target feature), the throttling rule (`Cpu.throttles`, `Policy.allow_throttling`), `TableSetRange` / `TablePickSized`; `odin run tool/test -- --levels` runs the packages that use it at every level. Tests in `simd_test.odin` build synthetic `Cpu` records with `CpuFromFeatures`: never test the manager through the global CPU. The rules for kernels (four accumulators, one procedure per level, no shared `#force_inline` helper across features, `fma` only with the feature) are in its README.
