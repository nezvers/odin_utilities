# ui: files and widgets, the inventory

The long list of what each file of the ui library holds and what each widget and style does. It is reference material: search it (`grep`) for the name you need instead of reading it whole, and read `ui/AGENTS.md` first. The source files carry a `Limits:` line each, and `odin run tool/todo -- limits ui` prints the limits of every widget.

- Immediate mode ui, layout ported from Clay (MIT, credited in README). Core files: `context.odin` (Storage, UiInit/Begin/End, widget state in a `Static_Handle_Map` of `UI_STATES`), `layout.odin` (Clay port: sizing, floating, clip, text wrap), `widgets.odin` (`Ui*` widgets, containers are `if UiPanel(...) {}` blocks through `@(deferred_in)`), `widgets_more.odin` (collapsing/tree, radio, selectable, tabs, drag, inputs, plots, color, menus, modal, titled window), `style.odin` (`StyleKind`, `DrawInfo` with rect + value 0..1 + name + actual, `Style` table of user procs), `render.odin` (`UiRender` only calls the style procs, so the ui shares the batch of the frame), `nav.odin` (focus by direction and the default actions of Godot: `ui.Action` ACCEPT/CANCEL/FOCUS_NEXT/UP../HOME/END/PAGE_*, set in `Input.actions` by the glue and applied in `UiBegin`; `UiNavigate`, `UiActivate`, `UiCancelled`, `UiNavLink/UiNavBlock` overrides, scroll into view, input agnostic), `rounded.odin` (radius as part of the shortest side, polygon into a caller buffer), `resize.odin` (`UiSplit` / `UiSplitFirst` / `UiSplitSecond`: two sections and the handle between them, side by side or stacked, the proportion kept by the split; `UiWindowResizable`: a window resized by its edges and corners that keeps its own position and size; `HitKind.NO_FOCUS`, `Clip.cut`, `Decl.absolute`: a child out of the flow at an offset, not a root). Node graph: `graph.odin` (model: `Graph` with nodes, ports, links, zip ties in handle maps, rules, events with user pointers, `GraphOrder`, `GraphCompile` buffer plan), `graph_cable.odin` (routes, bounds, distance, crossings, tie geometry), `graph_style.odin` (`GraphStyle`: routing/bounds/distance/draw procs), `tree.odin` (`Tree` model + `UiTree` over the virtual list), `inspector.odin` (`UiInspector`: element tree, usage, picking), `virtual.odin` (`UiVirtual` list and `UiTable`: only the rows in view are declared), `timeline.odin` + `timeline_widgets.odin` + `timeline_style.odin` (`UiTimeline`: tracks and clips model, rules, events, ruler, playhead; style procs in `default_style/timeline.odin`), `timeline_curve.odin` (shapes of the curve between automation points), `timeline_automation.odin` (plan + block renderer for the audio thread; its ramp and exponential loops are per level kernels in `timeline_automation_kernels.odin`, bench: `ui/tool/automation_bench`; many tracks: `AutomationCompileAll` / `AutomationRenderAll`), `timeline_points_edit.odin` (flip, mirror, rotate, repeat, stretch lives in timeline.odin), `timeline_history.odin` (undo and redo snapshots), `measure.odin` (cache of text sizes: every measure goes through `measureText`), `textarea.odin` (`UiTextArea`: rows, wrap, vertical movement), `accessibility.odin` (`UiAccessNodes`/`UiAccessDescribe`: the last frame as roles, names and states), `widgets_combo.odin` (`UiCombo`: a dropdown with a search field), `colorpicker.odin` (`UiColorPicker`, HSV and hex helpers; drawn by `default_style/color.odin`), `textundo.odin` (undo and redo of the focused text field and area), `textedit.odin` (selection, words, clipboard of the text field; `Input.modifiers`, actions COPY/CUT/PASTE/SELECT_ALL), `Decl.zoom` + `Style.zoom` (a container zoomed around its corner, `Painter.offset`), UI scale: `Painter.scale` in `default_style` (layout and styles in logical units, the glues scale drawing and divide the pointer; `InputPoll(scale)`), `widgets_audio.odin` (`UiKnob`, `UiFader`, `UiMeter`; style kinds KNOB/FADER/METER), `dock.odin` (`Dock` layout as plain data, `UiDock`: tabs and splits moved by dragging a tab), `graph_history.odin` (`GraphHistory`: undo and redo snapshots, `graph.serial`), `graph_layout.odin` (`GraphAutoLayout`), `graph_widgets.odin` (`UiGraph`, `UiGraphNode`, `UiGraphPin`, `UiGraphMinimap`, cuts and ties), `default_style/graph.odin`, `graph_test.odin`, `demo_common/demo_graph.odin`.
- The look follows Baldr (github.com/BuLEEto/Baldr, zlib, credited in `default_style/default_style.odin` and the README; no code of it): `THEME_DARK` / `THEME_LIGHT` (the output of `ThemeFromAccent` for Baldr's blue: a test keeps the constants equal to the generator; the same pixels as its gallery pictures), `theme_make.odin` (`ThemeFromAccent(color, dark)`: a port of Baldr's `theme_from_seed`, marked as altered as zlib asks; `ColorFromOklch` / `ColorToOklch` / `ColorContrast`; colors that sRGB does not have lose chroma, they are not clamped; tests in `theme_make_test.odin`: `odin test ui/default_style`), `Face` (REGULAR, STRONG, ITALIC, MONO, MONO_STRONG, STRONG_ITALIC, MONO_ITALIC, MONO_STRONG_ITALIC: every combination of the tags strong / italic / mono has a face, `TagFace` picks it, `FaceFallback` is the nearest one for a glue that lacks it; the vector text uses the last 8 of the 16 faces of the atlas, the kit allows 16 fonts: the style sets `painter.face`, the glue draws Inter / JetBrains Mono), `painter.draw_icon` (Lucide through the `icons` library, `ui_default.LucideIcon(.SAVE)` is a `ui.Icon`; numbers from 0x1000), button variants by tag ("primary", "secondary", "outline", "ghost", "danger"), "thin" sliders and progress bars, texts by tag ("title", "dim", "mono": tags reach text elements, and a text is measured with its tags: `ctx.measure_tags` / `UiMeasureHasTag`, the measure cache keys on them, `ui_default.Measure` picks the face with `TagFace`), theme areas (`ThemeAreaSet(&painter, n, theme)` + `UiTagged(ctx, ThemeAreaTag(n))`: a part drawn in its own theme, through `Style.before_draw`, which `UiRender` calls before every draw command), `RingRounded` (focus rings are outlines), `Shadow`, `StateColor` / `StateWash`, `RowBox` (rows are selected in the soft accent so composed rows stay readable). `markdown.odin` (`UiMarkdown(ctx, source)`: headings, wrapped paragraphs, nested lists, quotes, fenced code, rules, tables (`MarkdownTableCell`), read block by block every frame with `MarkdownNext`, inline marks stripped by `MarkdownInline` into the frame text; paragraphs, list entries and quotes are rich text; tests in `markdown_test.odin`), `richtext.odin` (`UiRichText(ctx, name, source, scale, max_width)`: a wrapped paragraph with runs of styles from Markdown marks, lines broken by the widget for last frame's width, one text per run tagged "strong"/"italic"/"mono"/"link"; a link is an INTERACTIVE element, `UiRichText` and `UiMarkdown` return `(address, clicked)`; `RichNext` is the reader; tests in `richtext_test.odin`), `settings.odin` (`Settings` in `ctx.settings`, `UiSettings`: double click time, `multi_click_limit`, drag distances, `extend_modifier`), `keymap.odin` (`KeyMap` of `Binding`s per `Action`, `KeyMapActions` with an `InputProbe`, `KeyMapConflict`, `KeyMapFromCodes(DefaultKeys, DefaultPad)` the default table for the key numbers of a framework; the tables are `ui_kit.KeyMapOf()`, `ui_raylib.KeyMapOf()`, `ui_karl2d.KeyMapOf()` and the glues have `TextureRegister` for glyph textures; tests in `settings_test.odin`, `keymap_test.odin`, `kit/ui_kit_test.odin`), `glyph.odin` (`Glyph`, `GlyphProc`, `UiGlyph`, `UiBindingGlyph`, `UiBindingField`: the picture of an input, a keycap or a pad button, a texture of the program's own through `Painter.draw_texture`; style kind `GLYPH`, drawn by `default_style/glyph.odin`; the kit's lookup is `ui_kit.GlyphOf`, textures `ui_kit.GlyphTextures`, `ui_kit.BindingPressed`; tests in `glyph_test.odin`), `highlight.odin` (`TextHighlight` proc + `TextSpan`: `UiTextArea(..., highlight, highlight_user)` declares a text per span of a row, tagged `SYNTAX_*`; `HighlightCode` with a `HighlightLanguage`, `HIGHLIGHT_ODIN`; a `state` number per row carries block comments and raw strings, kept in the row cache of the area (`areaStates`); colors in `ui_default.SyntaxColor`), `complete.odin` (`UiComplete(ctx, area_name, buffer, &length, items, trigger)` declared BEFORE the `UiTextArea` or `UiTextField` of the same name: a list under the caret (`WidgetState.caret`) of the items that contain the word after the trigger, takes UP/DOWN/ENTER/ESCAPE out of `ctx.input`, rows are NO_FOCUS, sets `own_vertical` while open, pushes an undo step; `CompleteQuery`; tests in `complete_test.odin`), `select.odin` (texts inside of the tag `TEXT_SELECTABLE` are selected by press and drag over lines and texts: `ctx.select` holds two `SelectPoint`s (group + element index of the frame or row of a list + cell + byte; `SelectKey` orders them: a text is 2 * index + 1, a list 2 * its base, then its slot, the row, the cell; the cell is `TextData.select_cell`, numbered by `TextOpen` among the selectable texts of the row), `UiSelectRows` / `UiSelectRow` / `SelectRowText` tell the selection about a list that declares only its rows in view and `selectCopyGroup` copies the rows between the ends from the program's text, `VirtualList.text = true` leaves the pointer of a list to the selection, `UiTextSelectionKeep` (`keep_press`: scroll bars, table headers and column edges do not let the selection go), `UiTableCell` sets `cell_column` so that the cell of a text in a table is its column, `UiSelectRows(..., cells, scroll, row_height)` lets Shift + up and down step by rows through `selectGroupStep`, letters and pages through `selectGroupMove` (on the program's texts: also for rows out of view), and scroll the list (`selectReveal`), `selectAfterLayout` in `UiEnd` finds the line under the pointer and gathers the copy text, `selectLineCommand` in `textCommands` emits TEXT_SELECTION under a line; `UiTextSelected`, `UiTextSelectionClear`; tests in `select_test.odin`), `textformat.odin` (`UiTextWrap`, `UiTextLinePrefix`, `UiTextSelectionOf`: the commands of an editor's buttons on the selection a text widget keeps, toggling, focus back to the widget, an undo step; tests in `textformat_test.odin`), `ansi.odin` (`AnsiNext` reads SGR escape sequences into an `AnsiState` run by run, `UiAnsiLine` / `UiAnsiText` draw output as texts in the code face with `TextConfig.color` and the tags strong / italic / dim; palettes `ANSI_COLORS_DARK` / `_LIGHT`; a log, not a screen of cells; tests in `ansi_test.odin`), `ansi_screen.odin` (`AnsiScreen` over caller cells, the rows a ring (`top`, `screenRowCells`: a whole screen scroll copies nothing; read and write cells through `screenCell` / `screenRowCells`, never `screen.cells[row * columns]`), printable ASCII written in runs (`screenPutRun`, a cell as two words; `asciiRunLength` finds the run eight bytes at a time) with `AnsiScreen.bytewise` as the reference path (a test compares them on random streams), `ui/tool/ansi_bench` measures it: `AnsiScreenMake`, `AnsiCell` is 16 bytes (a bit field of the character and two more, 3 byte colors, an attribute bit field: build with `AnsiCellMake`, read the style with `AnsiCellStyle`, never write a struct literal of it), `AnsiScreenWrite` (a state machine over bytes: CSI cursor moves, erase, insert/delete, SGR via `ansiApply`, OSC and charsets skipped, UTF-8 and sequences may be cut between writes), scroll regions (`margin_top` / `margin_bottom`, `ESC [ t ; b r`, line feed, reverse index, `L` `M` `S` `T` work inside of it; history only when it is the whole screen), `UiAnsiScreen` draws rows of runs of one style in `Fixed` cell widths, a cursor block, the wheel scrolls the history (`AnsiScreenMake(..., history)`: a ring owned by the caller, `AnsiScreenScroll`, `AnsiScreenViewCell`); the alternate screen (`AnsiScreenMake(..., alternate)`: `screenAlternate` swaps `cells` and `alternate` on `?1049 / ?47 / ?1047` `h` / `l`, no history while it is shown); `AnsiCell` has `wide` / `continuation` / `mark` (`AnsiRuneWidth`, pairs repaired by `screenBreakPair` and `screenFixRow`); tests in `ansi_screen_test.odin`), `shortcut.odin` (`Chord`, `ChordFormat`, `UiShortcutField(ctx, name, &chord, pressed, key_name)`: listens after a click, takes the next key the program passes, Escape cancels, Backspace clears; drawn as a BUTTON with the tag "outline" / "primary"; tests in `shortcut_test.odin`), `date.odin` (`Date`, `DateWeekday` with Monday 0, `DateDaysInMonth`, `DateAddMonths`; `UiDateField`: a DROPDOWN box with `icon = .CALENDAR` and a popup of `DATE_CELL`s, the shown month kept in `WidgetState.cursor` as a count of months; `UiTimeField`: a `UiCombo` over the times of a day; tests in `date_test.odin`), `chart.odin` (`UiChart` with a caller owned `ChartView`: LINE, AREA, BAR, SCATTER, round axis steps, nearest point under the pointer, a click picks, the navigation walks; the view keeps the slices of the series, so they have to outlive the frame: keep them in the state, the compiler warns about a local array; look in `default_style/chart.odin` with Baldr's color blind safe palette; tests in `chart_test.odin`). `widgets_extra.odin`: `UiSwitch`, `UiBadge` (`Tone`), `UiChip`, `UiTag`, `UiAvatar`, `UiSegmented`, `UiBreadcrumbs`, `UiSpinner`, `UiTitle`, `UiLabelDim`, `UiCard`, `UiInteract`; `UiButton(..., icon = ...)`, `DrawInfo.icon`; their look in `default_style/extra.odin`, tests in `widgets_extra_test.odin`. `DEFAULT_METRICS` did not change (the scripts of the demos click at numbers of the layout); a text size is the height of its line box, so 16 is Inter at 13 px per em, the label size of Baldr.
